# FitLytix product polish plan

## Goal
Turn the existing prototype into one cohesive, investor-ready Persian-first sports-tech experience, with a complete public website and a clear path into the product.

## Public website
- Rebuild the home page around «بدنت را بشناس. مسیرت را بساز.» with a full-width product-led opening and live-looking performance visuals.
- Add visual sections for the six-stage journey: Assess → Understand → Plan → Train → Measure → Adapt.
- Present all five sports with subtle, consistent sport accents.
- Explain Fitness DNA, adaptive programs, performance tracking, and AI + human coaching through product visuals rather than chatbot language.
- Add a concise pricing preview, FAQ, final conversion section, polished footer, and responsive mobile navigation.

## Product flow
- Keep the existing registration, login, assessment, athlete, coach, plans, and checkout screens.
- Correct the journey after sport assessment so users choose AI, human, or hybrid coaching before receiving a suggested plan.
- Preserve clear mock labels for OTP, AI output, storage, and payment; no live-service claims.
- Tighten the assessment experience and flagship dashboard presentation where necessary for consistency with the new public site.

## Design system and quality
- Preserve the dark charcoal and orange system, while using neutral surfaces and restrained sport-specific colors.
- Use stable responsive layouts, controlled motion, accessible controls, and Persian RTL throughout.
- Add route-specific social metadata fields where missing.
- Verify desktop and mobile rendering, navigation, the main conversion path, and the latest build diagnostics.

## Technical notes
- Continue using the existing TanStack React routes, TypeScript domain modules, shadcn controls, and mock service boundaries.
- Keep backend-ready boundaries intact; no database or external integrations are added in this scope.
- Prefer focused additions to the existing components and routes rather than replacing the established architecture.
